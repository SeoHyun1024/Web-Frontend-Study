# ⚙️[기능추가][about-me] 포토 덤프 섹션 구현

## 📝 개요

about-me 페이지 포토 덤프 섹션 구현

- 관련 파일: `html-css/about-me/index.html`, `html-css/about-me/style.css`
- 참고 자료: 과제 원본의 레이아웃 이미지(`image.png`), 화면 기록 영상
- 참고 이미지와 동일하게 배치 (각 사진 간 간격(gap) 동일, 반응형은 고려하지 않아도 됨)

## ✅ 구현 명세

- [ ] `grid` layout 사용
- [ ] 첨부한 사진과 동일한 레이아웃 구현

## ❤️‍🔥 심화

- [ ] 이미지 `hover` 시 사진 확대 (정해진 영역 안에서 사진이 커지는 방식)
