# ⚙️[기능추가][about-me] 네비게이션(사이드 목차) 구현

## 📝 개요

about-me 페이지 사이드 목차 네비게이션 구현

- 관련 파일: `html-css/about-me/index.html`, `html-css/about-me/style.css`
- 참고 자료: 과제 원본의 이미지(`image.png`), 화면 기록 영상

## ✅ 구현 명세

- [ ] 스크롤 시에도 고정(Sticky)
- [ ] 항목 클릭 시 해당 섹션으로 스크롤되어 이동
- [ ] `hover` 시 색상 변경

## ❤️‍🔥 심화

- [ ] 맨 위/맨 아래 항목의 모서리 반경을 가운데 항목과 다르게
  - 가운데 항목: 네 반경 모두 동글
  - 맨 위 항목: 위 두 반경만 동글
  - 맨 아래 항목: 아래 두 반경만 동글
