# ⚙️[기능추가][about-me] 사진첩(가로 스크롤 뷰) 구현

## 📝 개요

about-me 페이지 사진첩 가로 스크롤 뷰 구현

- 관련 파일: `html-css/about-me/index.html`, `html-css/about-me/style.css`
- 참고 자료: 과제 원본의 화면 기록 영상 (가로 방향 스크롤, 무한 스크롤)

## ✅ 구현 명세

- [ ] 스크롤이 생길 만큼 충분한 사진
- [ ] 가로 방향 스크롤 구현 (스크롤 스냅 적용)
- [ ] 스크롤바가 보이지 않도록 구현 (참고 영상 참고)
- [ ] 모든 사진은 찌그러지지 않아야 함

## 🔭 심화

- [ ] 끊김 없는 `무한 루프 배너` 구현
