# ⚙️[기능추가][about-me] 헤더 구현

## 📝 개요

about-me 페이지 상단 헤더 구현

- 관련 파일: `html-css/about-me/index.html`, `html-css/about-me/style.css`
- 참고 이미지: 과제 원본의 `image.png`

## ✅ 구현 명세

- [ ] 좌측: 미니 프로필 로고(또는 아바타), 가운데: 이름/타이틀, 우측: 소셜 아이콘(github, linkedin, tistory, velog 등)
- [ ] 3등분 레이아웃(좌/중/우가 각각 1/3 영역 차지)(화면 크기가 줄어들어도 동일해야 함)
- [ ] 스크롤과 무관하게 항상 상단 고정

## ❤️‍🔥 심화

- [ ] 아바타 이미지 hover 시 그림자 효과
- [ ] 소셜 아이콘 hover 시 위로 이동 and 색상 변경
- [ ] 소셜 아이콘 클릭 시 해당 링크로 연결
