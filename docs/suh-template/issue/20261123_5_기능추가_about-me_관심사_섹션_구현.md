# ⚙️[기능추가][about-me] 관심사 섹션 구현

## 📝 개요

about-me 페이지 관심사 카드 섹션 구현

- 관련 파일: `html-css/about-me/index.html`, `html-css/about-me/style.css`
- 참고 자료: 과제 원본의 이미지(`image.png`), 화면 기록 영상

## ✅ 구현 명세

- [ ] 카드 7개 이상 (이미지 / 제목 / 버튼 2개)
- [ ] 반응형 구현 (화면 크기에 따라 5 → 4 → 3 → 2 열로 변화)
- [ ] 카드 썸네일 크기 통일
- [ ] 이미지가 찌그러지지 않아야 함

## ❤️‍🔥 심화

- [ ] 카드 `hover` 시 상승/그림자 애니메이션
- [ ] 좋아요/싫어요 `hover` 시 자연스러운 컬러 변경
